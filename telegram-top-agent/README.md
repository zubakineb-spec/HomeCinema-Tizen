# Telegram Torrent Top 25 Agent

Ежедневный информационный агент: собирает **публичные показатели популярности** с доступных русскоязычных торрент-трекеров, объединяет дубликаты и отправляет в Telegram:

- ТОП-25 фильмов;
- ТОП-25 сериалов;
- публичный показатель источника (например, скачивания / сиды / скачивают сейчас);
- отметку, если одно произведение присутствует в нескольких источниках.

Агент **не отправляет** torrent-файлы, magnet-ссылки, URL страниц раздач и инструкции по обходу ограничений. Источники, требующие логина, cookies или обхода защит, намеренно не используются.

## Расписание

GitHub Actions запускает отчёт ежедневно в **13:00 UTC**, что соответствует **18:00 Asia/Yekaterinburg (UTC+5)**. Планировщик GitHub может фактически стартовать на несколько минут позже.

## Что нужно настроить один раз

В репозитории откройте **Settings → Secrets and variables → Actions → New repository secret** и создайте:

1. `TELEGRAM_BOT_TOKEN` — токен Telegram-бота от BotFather.
2. `TELEGRAM_CHAT_ID` — ID личного чата, группы или канала, куда бот имеет право отправлять сообщения.

Не добавляйте эти значения в код, README или Issues.

## Первый тест

Откройте **Actions → Telegram Torrent Top 25 → Run workflow**. Если секреты заданы правильно, бот отправит отчёт сразу.

## Локальная проверка без Telegram

```bash
pip install -r requirements.txt
DRY_RUN=1 python src/main.py
```

## Источники

В первой версии подключены публичные страницы Rutor и Kinozal. Архитектура рассчитана на добавление новых адаптеров. Недоступность одного источника не прерывает отчёт по остальным.
